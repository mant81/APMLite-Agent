# WAS 모니터링 요구사항

## 핵심 지표

| 지표 | 정의 | 기본 집계 단위 |
|---|---|---|
| 접속자 수 | 관측 기간에 요청을 발생시킨 식별된 사용자 수 | 1분 |
| TPS | 완료된 요청 또는 트랜잭션 수 / 초 | 1초·1분 |
| 동시 접속자 수 | 같은 시점에 처리 중인 요청 수 또는 활성 세션 수 | 순간값·최대값 |
| 히트 수 | HTTP 요청·트랜잭션 완료 건수 | 1초·1분 |

사용자 식별자가 없거나 개인정보 수집이 허용되지 않는 경우 접속자 수는 `unknown`으로 표시하고 임의로 세션 수를 접속자 수로 부르지 않는다.

## 히트 수 기반 경고

경고 규칙은 다음 정보를 가져야 한다.

- 대상: 전체 서비스, URI, 트랜잭션 또는 서비스 그룹
- 시간 창: 예를 들어 최근 1분
- 조건: 절대 건수, TPS, 이전 기간 대비 증감률
- 임계값: 경고·위험 단계
- 중복 억제 및 해제 조건
- 발생 시각, 관측값, 기준값, 대상, 샘플링 조건

## 현재 구현 상태

현재 에이전트는 JVM 샘플, JDBC 실행 건수, 느린 SQL, 대시보드 기반과 Servlet 요청의 전체·URI별 히트 수, 경과 시간으로 환산한 TPS, URI별 평균·최대 응답시간, 현재 처리 중 요청 수 계측을 제공한다. `/api/traffic`에서 해당 값을 조회할 수 있다. 사용자 식별자가 없는 환경의 접속자 수와 히트 기반 경고는 아직 구현되지 않았으므로 개발 갭으로 관리한다.

## SQL 실행 시간 잔디형 모니터

SQL 화면은 목록 중심 대신 시간 흐름을 한눈에 보는 잔디형 히트맵으로 제공한다.

- 가로축: 시간 순서
- 세로축: SQL 템플릿 또는 SQL 그룹
- 점 하나: 해당 시간 버킷에서의 실행 이벤트 또는 집계된 실행 그룹
- 색상: 실행 시간 구간을 표현한다. **3초 미만은 초록색**, **3초 이상 10초 미만은 노란색**, **10초 이상은 붉은색**으로 표시하고, 오류는 별도 색상으로 구분한다.
- 크기 또는 점의 농도: 동일 버킷의 실행 건수
- 점 선택: 실행 시각, 실행 시간, 건수, 오류 여부, SQL 템플릿, 바인딩 값 비수집 원칙을 확인한다.

기본 시간 버킷은 1분으로 두고, 조회 범위가 길어지면 5분·1시간으로 자동 집계한다. 초록색은 3,000ms 미만, 노란색 경계는 3,000ms, 붉은색 경계는 10,000ms로 둔다. 원본 SQL 파라미터와 비밀번호는 점 데이터나 상세 화면에 저장하지 않는다. 색상만으로 판단하지 않도록 임계값과 범례를 함께 표시한다.
